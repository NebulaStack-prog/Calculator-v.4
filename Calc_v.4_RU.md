## Часть 1. Основной документ.

### 1. Заголовок и базовая информация.

• **Название:** Calculator v.4

• **Назначение:** Проект № 15. Продукт.

• **Фаза проекта:** Phase II.

• **Технологический стек:** HTML (со встроенными CSS-стилями и JavaScript-кодом).

• **Статус проекта:** Полностью завершен.

### 2. Краткое описание проекта.

**Calculator v.4** – это веб-калькулятор, реализованный в виде одного HTML-файла, внутри которого размещены стили (в теге <style>) и логика (в теге <script>).

Приложение поддерживает базовые арифметические операции: сложение, вычитание, умножение и деление, а также работу со скобками и десятичными числами.

Особенностью проекта является тёмная неоновая тема оформления с подсветкой и анимацией кнопок при наведении, а также поддержка ввода с клавиатуры.

Калькулятор работает прямо в браузере — не требует установки и запускается двойным кликом по HTML-файлу.

Проект представляет собой полностью функциональное веб-приложение с интуитивным интерфейсом.

### 3. Четкие цели проекта.

• Создать работающий веб-калькулятор с понятным интерфейсом.

• Реализовать основные арифметические операции: +, -, *, /.

• Реализовать поддержку скобок для изменения порядка операций.

• Реализовать ввод десятичных чисел через точку.

• Реализовать обработку ошибок при некорректном выражении.

• Реализовать ввод с клавиатуры для удобства использования.

• Обеспечить адаптивный и привлекательный дизайн с анимациями.

• Использовать только стандартные веб-технологии в одном файле.

• Продемонстрировать подход к разработке одностраничных веб-приложений.

### 4. Компоненты проекта.

Проект состоит из одного HTML-файла, включающего все компоненты:

• calculator.html – единый файл, содержащий:
- разметку интерфейса (HTML),
- стили оформления (встроенный CSS в теге <style>),
- логику работы (встроенный JavaScript в теге <script>).

### 5. Инструкция по использованию.

- **5.1. Запуск:**

• Откройте файл calculator.html в любом современном браузере (Chrome, Firefox, Edge).

• Никаких дополнительных установок не требуется.

- **5.2. Цель приложения:**

• Выполнение простых арифметических вычислений.

• Ввод выражения через экранные кнопки или клавиатуру.

- **5.3. Управление:**

• Кнопки на экране (мышь): цифры 0–9, операторы +, -, ×, ÷, скобки (, ), точка ., кнопки C (очистить) и = (вычислить).

• Клавиатура:

• 0–9: ввод цифр.

• +, -, *, /: операторы.

• .: десятичная точка.

• (, ): скобки.

• Enter: вычислить результат (=).

• Escape: очистить экран (C).

- **5.4. Интерфейс:**

• Дисплей сверху — темный фон с зелёным неоновым текстом.

• Сетка кнопок 4×5:

• Серые — цифры и точка.

• Оранжевые — операторы (÷, ×, -, +).

• Зелёная (широкая) — кнопка =.

• Красная — кнопка C (очистка).

• Анимации: увеличение кнопки при наведении.

• Цветовая схема: тёмно-синий фон (#2c3e50), неоново-зелёный текст (#00ff88).

## Часть 2. Технический документ.

### 1. Цели разработки.

• Закрепить навыки работы с HTML и встроенными в него CSS и JavaScript.

• Изучить DOM-манипуляции, обработку событий и работу с eval().

• Реализовать ввод как мышью, так и с клавиатуры.

### 2. Использованные технологии.

• HTML – разметка интерфейса.

• Встроенный CSS (тег <style>) – оформление, Grid-раскладка, анимации.

• Встроенный JavaScript (тег <script>) – логика вычислений и обработка событий.

### 3. Архитектура проекта.

• Одностраничное приложение, размещённое в одном HTML-файле.

• Логика построена на глобальной переменной expression, хранящей строку выражения.

• Функции: appendChar(), clearDisplay(), calculate().

• Обработка клавиатуры через document.addEventListener('keydown', ...).

### 4. Структура проекта.

• **<style>:** стили для .calculator, .display, .buttons, button и классов .operator, .equals, .clear.

• **<body>:** контейнер .calculator с дисплеем (#display) и сеткой кнопок.

• **<script>:**

- appendChar(char) – добавление символа к выражению.

- clearDisplay() – сброс выражения.

- calculate() – вычисление результата через eval().

- Обработчик keydown для клавиатуры.

### 5. Ключевые компоненты системы.

• **Дисплей:** обновляется при каждом изменении expression.

• **Вычисление:** через eval() с обёрткой в try/catch для обработки ошибок.

• **Обработка клавиатуры:** сопоставление клавиш с действиями.

• **Стилизация:** CSS Grid, border-radius, box-shadow, transition.

### 6. Реализация пользовательского интерфейса.

• Интерфейс полностью реализован средствами HTML и встроенного CSS.

• Сетка кнопок через display: grid и grid-template-columns: repeat(4, 1fr).

• Кнопка = растянута на 2 колонки через grid-column: span 2.

• Анимации через transition и transform.

### 7. Процесс разработки.

• Создание HTML-разметки калькулятора.

• Добавление встроенных CSS-стилей с тёмной темой.

• Реализация логики через встроенный JavaScript.

• Добавление обработки клавиатуры.

• Финальная настройка анимаций и цветов.

### 8. Основные сложности и способы их решения.

• **(1) Сложность:** обработка некорректных выражений.

**Решение:** обёртка eval() в try/catch с выводом сообщения «Ошибка!».

• **(2) Сложность:** поддержка ввода с клавиатуры.

**Решение:** глобальный обработчик keydown с проверкой e.key.

• **(3) Сложность:** адаптация под разные размеры экрана.

**Решение:** использование flex для центрирования и относительных единиц.

### 9. Текущие ограничения проекта.

• Использование eval() небезопасно для сложных сценариев.

• Нет истории вычислений.

• Нет поддержки научных функций (sin, cos, √).

• Нет памяти (M+, M-, MR).

### 10. Возможные улучшения и планы развития.

• Замена eval() на собственный парсер выражений.

• Добавление истории вычислений.

• Добавление научных функций и констант (π, e).

• Реализация памяти калькулятора.

• Поддержка тем оформления (светлая/тёмная).
